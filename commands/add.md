# add — apply new owner material

Read [rules](../reference/rules.md) and [record](../reference/record.md).

1. Open/resume the write run, capture immutable new material and invocation, record clear answers/vetoes
   first, preserve owner/concurrent edits, and inspect changed/stale relevant baseline evidence.
2. Apply the whole supplied update before review: new behavior becomes FR, present-behavior change CH,
   preservation KEEP, explicit removal a tombstone/exclusion. Explicit owner supersession quotes old text;
   unexplained source contradictions retain both quotes as a question. `soft` leaves contradictory existing
   text and asks instead of superseding. Material outside this feature is named, not folded into scope.
3. Update baseline for newly touched source; refresh author facts semantically. No mandatory extra mapping
   or verifier dispatch. A settled marker is removed with its evidence; its question closes in the same
   update. Preserve all issued IDs and regenerate Open questions. Material changes clear Ready to Draft.
4. Use [substantive review](../reference/grill.md) for changed outcomes and affected dependencies. If
   supplied material only confirms already-reviewed behavior, verify applicability and reuse coverage;
   a new source does not automatically require repeating every check. Serious open decisions can defer
   final review. A chained resolve/ready consolidates the final review boundary.
5. Handle findings under [dispositions](../reference/dispositions.md); one correction/recheck by default.
   Lint/snapshot/close. Report superseded owner text, defaults and any remaining policy/review blockers.
